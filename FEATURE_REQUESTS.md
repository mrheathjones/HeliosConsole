# Feature Requests

A running brain dump of ideas and feature requests for HeliosConsole. Not all of these are planned or prioritized — this is just a place to capture ideas so they aren't lost.

## How to use this file

- Add new ideas under **Backlog** with a short description.
- Move items to **In Progress** when work starts.
- Move items to **Done** once shipped (or delete if no longer relevant).
- Feel free to add context, rough notes, or links — this doesn't need to be polished.

## Backlog

- **Entra ID authentication** — support signing in via Microsoft Entra ID.
- **User Profile** — add a user profile section/page.
- **Merge Device Search with Enrollments** — unify device search and enrollments into a single view/flow.
- **Fix light/dark mode in settings** — light/dark mode toggle in settings is broken.
- **Incorporate Self Service/App Usage** — surface Self Service and app usage data in the app.
- **Fix Reports Export Button** — the export button on Reports is not working.
- **Sweep codebase to ensure no hard coded elements exist** — audit for hard-coded values (URLs, secrets, config, etc.) and replace with proper configuration.
- **Create Standalone mode** — support running the app in a standalone mode.
- **Enhance Logging** — improve logging throughout the app.
- **App controlled directory** — app-controlled directory feature.
